#Proyecto de Burocracias

Este proyecto contiene los archivos del Censo Nacional de Gobiernos Estatales 2023 y el código con el que se manipularon para realizar la entrada "Las burocracias estatales en México: cada vez más grandes, pero poco profesionales". Disponible en https://federalismo.nexos.com.mx/2023/11/las-burocracias-estatales-en-mexico-cada-vez-mas-grandes-pero-poco-profesionales/


#Requisitos

Para ejecutar el código es necesario tener instaladas las paqueterías tidyverse, viridis, y pachwork
